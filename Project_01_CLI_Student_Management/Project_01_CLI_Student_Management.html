4. Ma'lumotlar Modeli: models.py (OOP va Validatsiya)

Tizim markazida Student sinfi turadi. U talabaning shaxsiy ma'lumotlarini o'zida birlashtiradi va ma'lumotlar yaxlitligini (Data Integrity) qat'iy tekshiradi.

Talaba Atributlari va Tiplari:
  • student_id: int — Unikal ketma-ket raqam
  • full_name: str — To'liq ism (Titlecase)
  • email: str — Unikal elektron pochta
  • grades: list[float] — Imtihon ballari (0-100)
  • enrolled_date: str — Sana (YYYY-MM-DD)
Validatsiya Qoidalari (_validate):
  • Ism bo'sh bo'lmasligi va kamida 3 belgi
  • Email ichida @ va . mavjudligi
  • Har bir baho 0 <= baho <= 100
  • Buzilsa ValueError chiqariladi
class Student:
    def __init__(self, student_id: int, full_name: str, email: str, grades: list = None):
        self.student_id = student_id
        self.full_name = full_name.strip().title()
        self.email = email.strip().lower()
        self.grades = grades if grades is not None else []
        self._validate()

    def average_grade(self) -> float:
        if not self.grades: return 0.0
        return round(sum(self.grades) / len(self.grades), 2)

    def academic_status(self) -> str:
        avg = self.average_grade()
        if not self.grades: return "Baholanmagan"
        elif avg >= 86.0: return "A'lochi (Honors) 🌟"
        elif avg >= 71.0: return "Yaxshi (Good) 👍"
        elif avg >= 55.0: return "Qoniqarli (Passing) ⚠️"
        else: return "Qarzdor (Failing) ❌"

5. Fayl Tizimi va Doimiylik: storage.py (JSON Persistence)

Operativ xotiradagi (RAM) Python ob'ektlari dastur yopilganda o'chib ketadi. StorageManager ma'lumotlarni qattiq diskdagi JSON formatiga o'tkazish (Serialization) va qayta tiklash (Deserialization) xizmatini beradi.

Fayl Yo'lini Xavfsiz Aniqlash (Absolute Path Resolution):

Dastur terminalda qayerdan ishga tushirilishidan qat'i nazar xato qilmasligi uchun: base_dir = os.path.dirname(os.path.abspath(__file__)) va os.path.join(base_dir, "data", "students.json") qo'llaniladi.

        except (json.JSONDecodeError, Exception) as e:
            print(f"⚠️ Ogohlantirish: JSON o'qishda xatolik: {e}")
            return []

    def save_students(self, students: list[Student]) -> bool:
        try:
            data = [s.to_dict() for s in students]
            with open(self.file_path, mode="w", encoding="utf-8") as f:
                json.dump(data, f, indent=2, ensure_ascii=False)
            return True
        except Exception as e:
            return False

6. Biznes Mantiq va Tahlil Dvigateli: manager.py

StudentManager sinfi servis qatlami (Service Layer) hisoblanadi. U talabalar ro'yxatini xotirada keshlaydi, CRUD amallarini bajaradi va ma'lumotlar o'zgarganda ularni avtomatik tarzda StorageManager orqali diskka saqlaydi.

CRUD & Boshqaruv:
  • add_student() — Dublikat emailni tekshiradi, keyingi bo'sh ID ni hisoblaydi (max(id) + 1).
  • search_students() — Katta-kichik harfni ajratmasdan ism yoki emaildan qidiradi (Substring).
  • update_student() — Ism yoki emailni qayta tekshirgan holda tahrirlaydi.
  • delete_student() — Talabani ro'yxatdan o'chirib diskni yangilaydi.
Tahliliy Funksiyalar (Analytics):
  • get_top_students(top_n=5) — Lambda ifodasi yordamida eng a'lochi talabalar reytingi.
  • get_statistics() — Guruhning umumiy GPA ko'rsatkichi, eng yuqori va past baholar.
  • all() va any() — Guruhda qarzdorlar borligini yoki hamma talabalar imtihondan o'tganligini aniqlash.
def get_top_students(self, top_n: int = 5) -> list[Student]:
    graded = [s for s in self.students if s.grades]
    return sorted(graded, key=lambda s: s.average_grade(), reverse=True)[:top_n]

def get_statistics(self) -> dict:
    graded = [s for s in self.students if s.grades]
    averages = [s.average_grade() for s in graded]
    return {
        "total_students": len(self.students),
        "class_average": round(sum(averages) / len(averages), 2) if averages else 0.0,
        "highest_avg": max(averages) if averages else 0.0,
        "lowest_avg": min(averages) if averages else 0.0,
        "honors_count": len([s for s in graded if s.average_grade() >= 86.0]),
        "has_failures": any(s.average_grade() < 55.0 for s in graded),
        "all_passing": all(s.average_grade() >= 55.0 for s in graded) if graded else False
    }

def print_student_table(students: list):
    if not students:
        print("\nℹ️ Hozircha tizimda talabalar mavjud emas.")
        return
    print("\n" + "-" * 75)
    print(f"{'ID':<5} | {'F.I.SH.':<22} | {'EMAIL':<22} | {'O\'RT.':<6} | {'STATUS':<15}")
    print("-" * 75)
    for s in students:
        print(f"{s.student_id:<5} | {s.full_name:<22} | {s.email:<22} | {s.average_grade():<6.1f} | {s.academic_status():<15}")
